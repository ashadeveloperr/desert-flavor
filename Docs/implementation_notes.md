  원인 ① 우물 성능 향상 +20%가 D2에서 순이익 +361 → +804(봇 배치의 물 병목을 풀어 줌). ② 난이도가 보유 자금 비례라 수익이 줄수록 D 상승도 느려져 적자 구간에 닿지 못함.

**근거:** `dotnet run --project Tools/SettlementSim` 시뮬레이션(원본 v0.8 회귀값 재현 + 규칙 후보 비교). 주요 근거:
- W3 변 중간점 방출이면 우물 꼭짓점에서 뻗은 수로에 물이 안 가서 원본 배치에서 물 0%.
- W4 단일 취수는 막힌 경로를 고르면 농장 0%·우물 물 40 남음 → 다중 취수 100%.
- W5 농장·우물을 수로로 두르는 자연스러운 배치가 모두 순환 → 금지하면 건설 거부.
- C2 건너뛰기는 값싼 작업이 석재를 먼저 써서 경매장 완공 8~24시간 지연.

- [확정] 규칙은 코드에 고정하고, [잠정] 값은 설정으로 뺀다. [미정]은 구현하지 않는다.

## 4. 확인 방법

1. Unity에서 `SampleScene`을 열고 Play를 누른다(디버그 세션이 이미 들어 있다. 새 씬이라면 메뉴 **Tools > Desert Settlement > 디버그 세션 만들기**).
2. 왼쪽 패널의 **샘플 배치 예약**을 누르면 v0.8 직렬 예시(우물·농장·채석장·광산·경매장·수로 3)가 대기열에 들어간다.
   직접 지으려면 도구 버튼을 고르고 타일(시설) 또는 변(수로)을 클릭한다. 물길을 막으려면 폐쇄 도구로 수로를 닫는다. 수로는 드래그로 이어 놓을 수 있다.
3. 왼쪽 위 배속 버튼(4x)으로 시간을 빠르게 돌리며 확인한다: 공사 진행률, 수로의 물 흐름 색, 시설의 물 부족 이유,
   자원·F 변화, 경매장 완공 후 첫 경매 예정 시각, 낮/밤 조명.
4. 카메라: WASD/화면 가장자리 이동, 휠 줌, Q/E 회전. 우클릭·Esc는 선택 도구.
5. 테스트: Window > General > Test Runner > EditMode·PlayMode > Run All, 또는 `bash Tools/unity-tests.sh All`(테스트 전용 사본 `.unity-testcopy/`에서 batch mode로 실행, 열린 에디터와 무관).
