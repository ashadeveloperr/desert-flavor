**읽는 법:** 항목마다 **고른 것 / 이유 / 다른 안 / 바꾸려면**을 적는다. '바꾸려면'은 설정 값이면 JSON 키, 규칙이면 코드 위치.
사용자가 직접 고른 것(대화에서 답한 것)은 **[사용자 결정]**, Claude가 고른 것은 **[자동]**으로 표시한다.
플레이해 보고 고칠 것이 생기면 해당 항목에 메모를 달거나 대화로 알려 주면 된다.
