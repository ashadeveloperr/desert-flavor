# 자동 결정 기록 (Claude가 추천안으로 정한 것)

2026-10-23 사용자 지시: "추천하는 대로 자동으로 만들고, 선택할 때마다 왜 그렇게 판단했는지 기록으로 남겨. 나중에 읽고 플레이해 본 다음 고치겠다."
→ 로드맵(`Docs/roadmap_2026-10-23.md`)을 순서대로 구현하면서, 사용자 확인 없이 고른 것을 여기에 모두 적는다.

**읽는 법:** 항목마다 **고른 것 / 이유 / 다른 안 / 바꾸려면**을 적는다. '바꾸려면'은 설정 값이면 JSON 키, 규칙이면 코드 위치.
사용자가 직접 고른 것(대화에서 답한 것)은 **[사용자 결정]**, Claude가 고른 것은 **[자동]**으로 표시한다.
플레이해 보고 고칠 것이 생기면 해당 항목에 메모를 달거나 대화로 알려 주면 된다.
