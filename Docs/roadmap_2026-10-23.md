# 로드맵 — 초기 기획 완성까지 (2026-10-23 정리)

통합 기획서(`Docs/desert_settlement_game_design_checkpoint_2026-10-20.md`)와 구현 기록(`Docs/implementation_notes.md`)을 대조해 **아직 구현되지 않은 기획 항목**을 모은 목록.
세부 결정·측정은 항목별 작업 목록 문서(예: `Docs/work_items_2026-10-23.md`)에 쓰고, 여기에는 순서와 상태만 둔다.
표기: **[결정]** 사용자가 정함 · **[제안]** Claude가 낸 안(확정 전) · **[질문]** 정해 주셔야 구현할 수 있음.
상태: ☐ 할 일 · ◐ 진행 중 · ☑ 완료.

**추천 순서(2026-10-23 제안):** 재해 구상을 기다리는 동안 1-② 물탱크 → 재해 구상이 오면 1-① → 1-③ → 1-④ → 1-⑤ → 1-⑥ → 1-⑦.
2단계는 1단계 사이사이에 넣을 수 있고, 3단계는 규칙이 다 정해진 뒤에 한다.
